# ReportGuard

ReportGuard er en Outlook-integreret platform til servicerapporter,
leverandørskabeloner og beskyttelse mod dobbelt afsendelse.

Projektet er i planlægningsfasen. Arkitektur, modeller og tekniske beslutninger
findes i [`docs/`](docs/README.md).

## Branches

- `dev` er standardbranch og samlingspunkt for det løbende arbejde.
- Feature-branches oprettes fra `dev` og flettes tilbage via pull requests.
- `main` opdateres kun via en release-pull-request fra `dev`.
